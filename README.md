Kminus es un proyecto de creación de una silla de ruedas todoterreno. En este repo se puede encontrar codigo de la electrónica, controladora...

Una de las controladoras utilizadas por su capacidad de controlar 2 motores es la vesc duet, la cual la manejamos mediante scripts en el lenguaje LispBM, adjunto un repo donde se puede encontrar la documentación a este lenguaje https://github.com/vedderb/bldc/blob/master/lispBM/README.md
